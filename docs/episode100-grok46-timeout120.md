# Synthetic timeout demonstration

This is an offline technical-preview profile, not a paid-run result or authorization.
The fictional series in `tools.episode100_grok46_timeout120.SERIES` uses a total
of 20, committed carry of 2 and remaining cap of 18 (USD units purely for the
budget example). Evidence digests refer to invented strings, not execution files.
No previous approval transfers to this source or profile.

The profile sets a 120-second turn deadline and 12000-second episode admission
bound. Other profiles retain their own bounds. The 100-call whole-episode cap,
no retries, payload-preparation deadline accounting, exact series validation,
and consume-before-credential custody remain enforced. None of this changes Core
or the domain fixture. Offline SDK transports are not evidence of provider behavior.

The live launcher defaults to refusal without a new exact-source, output, scope,
profile and cap-bound operator approval. No such approval is included here.
Publication and any future paid run each require separate human approval.
